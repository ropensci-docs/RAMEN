# Package index

## All functions

- [`findCisSNPs()`](https://docs.ropensci.org/RAMEN/reference/findCisSNPs.md)
  : Find cis SNPs around a set of Variable Methylated Loci (VML)
- [`findVML()`](https://docs.ropensci.org/RAMEN/reference/findVML.md) :
  Identify Variable Methylated Loci in microarrays
- [`lmGE()`](https://docs.ropensci.org/RAMEN/reference/lmGE.md) : Fit
  linear G, E, G+E and GxE models and select the winning model
- [`medCorVMR()`](https://docs.ropensci.org/RAMEN/reference/medCorVMR.md)
  : Compute the median probe methylation pearson correlation for each
  Variable Methylated Region (VMR).
- [`nullDistGE()`](https://docs.ropensci.org/RAMEN/reference/nullDistGE.md)
  : Simulate a delta R squared null distribution of G and E effects on
  DNAme variability
- [`selectVariables()`](https://docs.ropensci.org/RAMEN/reference/selectVariables.md)
  : Selection of relevant environment and genotype variables associated
  with Variably Methylated Loci (VML)
- [`summarizeVML()`](https://docs.ropensci.org/RAMEN/reference/summarizeVML.md)
  : Summarize the methylation states of Variable Methylated Loci (VML)
- [`test_covariates`](https://docs.ropensci.org/RAMEN/reference/test_covariates.md)
  : Concomitant variable example data set
- [`test_environmental_matrix`](https://docs.ropensci.org/RAMEN/reference/test_environmental_matrix.md)
  : Environmental exposures example data set
- [`test_genotype_information`](https://docs.ropensci.org/RAMEN/reference/test_genotype_information.md)
  : Genotype metadata example data set
- [`test_genotype_matrix`](https://docs.ropensci.org/RAMEN/reference/test_genotype_matrix.md)
  : Genotype matrix example
- [`test_methylation_data`](https://docs.ropensci.org/RAMEN/reference/test_methylation_data.md)
  : Methylation data matrix example
- [`ultrastable_cpgs`](https://docs.ropensci.org/RAMEN/reference/ultrastable_cpgs.md)
  : Ultrastable probes
